# Project Title

## Overview
This project is a full-stack Airbnb clone with features like property booking, user authentication, and reviews. It demonstrates my skills in React, Node.js, and MongoDB.

- Reviews and ratings system

- React

## How to Run
1. Clone the repository.
2. Install dependencies using `npm install`.
3. Run the project using `npm start`.
